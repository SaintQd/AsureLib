## AsureLib

Плагин-библиотека, предоставляющий общие классы и методы для работы других плагинов экосистемы Asure.

---

## Модули и возможности

- **Файлы конфигураций (ResourceUtils)**: Автоматическая генерация YAML-конфиг-файлов на основе шаблонов, заданных в ресурсах плагина.
- **Локализация (LangManager)**: Создание языковых YAML-файлов с плейсхолдерами, поддерживающими формат MiniMessage. Языковой файл 
выбирается для плагина в целом, а не для каждого клиента, но может быть настроен под использование языковых файлов ресурс-паков.
- **GUI**: Создание настраиваемых GUI на основе инвентарей контейнеров. GUI поддерживает различные действия при нажатии на иконки
(вызов команд, выдача предметов, отображение сообщений, оплата нажатия валютой VaultAPI, открытие другого меню и др.).
GUI регистрируются на основе NamespacedKey и реализуются непосредственно в папках наследующих библиотеку плагинов.
- **DiscordSRVManager**: Интеграция с плагином DiscordSRV. Упрощает процесс создания Embed-сообщений. Используется Discord-ботами экосистемы Asure.
- **MMAbilityData**: Интеграция с MythicMobs. Предоставляет возможность вызывать скиллы MythicMobs для игроков или сущностей посредством API.
- **RomanNumber**: Класс, реализующий возможность использования римского исчисления.
- **SQLUtils**: Класс-помощник для работы с базами данных диалекта MySQL, реализующий проверки на наличие базы данных, 
конкретной таблицы в ней и на соответствие таблицы заданной схеме.
- **AsureUtils**: Класс-помощник, содержащий различные статичные методы, использующиеся в других плагинах экосистемы Asure.
- **WeightedCollection**: Класс, реализующий коллекцию объектов, позволяющую получить случайный объект из неё на основе заданного веса.

## Сборка

Для компиляции требуется JDK 25 или выше.\
Чтобы запустить сборку, скопируйте проект и запустите сборку через `gradle build`.\
Скомпилированный артефакт будет находиться в папке `build/libs/`.

## Поддержка

Данный плагин разрабатывался для конкретного проекта. Многие возможности плагина были созданы с целью закрыть определённую нишу в
контенте, и могут являться рудиментарными для остальных проектов. При необходимости каждую конкретную функцию плагина можно отключить или перенастроить.

В связи с предназначением плагина услуги по его поддержке предоставляются только в рамках оригинального проекта. Для получения
поддержки (исправление багов, добавление возможностей) в рамках стороннего проекта, вы можете обратиться к автору плагина и оформить заказ консультации.
